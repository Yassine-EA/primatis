# Contrat d’intégration — Georges Lemaître

## Destination

```text
docs/design/assets/public/georges-lemaitre/
```

## Hero

Fonds :

- ≥ 1440 px : `georges-lemaitre-background-1920.webp`
- 769–1439 px : `georges-lemaitre-background-1280.webp`
- ≤ 768 px : `georges-lemaitre-background-768-mobile.webp`

Portrait :

- desktop : `/assets/shared/portraits/georges-lemaitre-1024.webp` ;
- tablette : `/assets/shared/portraits/georges-lemaitre-768.webp` ;
- mobile : `/assets/shared/portraits/georges-lemaitre-480.webp`.

Le portrait doit rester un élément `img` séparé. Utiliser `alt="Portrait illustré de Georges Lemaître"` et ne pas le présenter comme une photographie d’archive authentifiée.

## Sections scientifiques

- Univers en expansion : `/assets/shared/editorial/editorial-cosmos-960.webp` et variante 640 ;
- Atome primitif : variantes 1280/768.

Tous les titres, dates, explications et légendes restent en HTML. Pour l’atome primitif, la légende doit préciser qu’il s’agit d’une représentation artistique.

## Charleroi

`/assets/shared/editorial/editorial-observatory-960.webp` est un décor astronomique générique avec `alt=""`. Il ne constitue pas une vue de Charleroi. Une future photographie locale ne pourra le remplacer qu’avec source et licence documentées.

## Pourquoi PRIMATIS

Utiliser les variantes `/assets/shared/editorial/lemaitre-observatory-banner-*` en décor de fond. Le texte de justification reste du HTML.

## Interdictions

- ne pas cuire la formule ou les citations dans les images ;
- ne pas inventer de citations ;
- ne pas afficher de sélection d’œuvres sans curation réelle ;
- ne pas fusionner définitivement portrait et fond.
