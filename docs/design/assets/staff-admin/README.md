# PRIMATIS — ASSET-RESET-04 — Staff/Admin

Pack mutualisé pour le shell et les écrans Staff/Admin.

## Contenu

- `shell/` : décor d’observatoire transparent pour le bas de la sidebar ;
- `empty-states/` : illustration neutre réutilisable pour les listes et tableaux vides ;
- `docs/` : manifeste, provenance, règles métier et mapping PrimeIcons ;
- `preview/` : planche et composition de validation.

## Dépendances déjà livrées

- logo inversé : `assets/brand/primatis-logo-horizontal-light.svg` ;
- symbole inversé : `assets/brand/primatis-symbol-light.svg` ;
- couverture compacte : `assets/fallbacks/cover-compact.svg` ;
- image invalide : `assets/fallbacks/image-error.svg`.

Ces fichiers du socle global ne sont pas dupliqués dans ce pack.

## Règles

- avatars en initiales CSS, jamais en faux portraits ;
- graphiques uniquement avec des données réelles et un composant accessible ;
- icônes métier et CRUD via PrimeIcons ;
- actions sensibles avec libellé ou `aria-label` explicite ;
- aucune fonctionnalité absente du backend ne doit être légitimée par un visuel.
