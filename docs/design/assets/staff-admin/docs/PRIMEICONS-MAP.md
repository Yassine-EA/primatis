# PRIMATIS — PrimeIcons — Staff/Admin

| fonction | classe recommandée |
|---|---|
| tableau de bord | `pi pi-chart-bar` |
| catalogue | `pi pi-book` |
| exemplaires | `pi pi-clone` |
| prêts | `pi pi-arrow-right-arrow-left` |
| réservations | `pi pi-bookmark` |
| amendes | `pi pi-receipt` |
| utilisateurs | `pi pi-users` |
| articles | `pi pi-file-edit` |
| paramètres | `pi pi-cog` |
| rapports | `pi pi-chart-line` |
| recherche | `pi pi-search` |
| filtre | `pi pi-filter` |
| ajouter | `pi pi-plus` |
| modifier | `pi pi-pencil` |
| consulter | `pi pi-eye` |
| supprimer | `pi pi-trash` |
| enregistrer | `pi pi-save` |
| annuler | `pi pi-times` |
| exporter | `pi pi-download` |
| succès | `pi pi-check-circle` |
| avertissement | `pi pi-exclamation-triangle` |
| erreur/blocage | `pi pi-times-circle` |

Une icône accompagnée d’un texte visible reçoit `aria-hidden="true"`. Un bouton composé uniquement d’une icône reçoit un `aria-label`, un tooltip et une cible d’au moins 44×44 px. Une suppression conserve toujours un libellé explicite dans sa confirmation.
